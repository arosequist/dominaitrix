# Registry contract

The registry is an HTTPS-hosted static directory generated by `pnpm registry:build`. It is deployment output, not an additional source tree, and is excluded from Git.

`index.json` contains a schema version, generation timestamp, and adapter records. Each record includes:

- stable adapter `id` and semantic `version`;
- display `name` and concise `description`;
- Chrome match patterns;
- execution `world`, normally `USER_SCRIPT`;
- canonical relative source path;
- SHA-256 digest of the exact published JavaScript; and
- tool summaries and compatibility metadata used during review and in the extension UI.

The client installs every adapter in the index. It refreshes a registration whenever its source digest, version, match patterns, or execution world changes, and removes registrations withdrawn from the registry. Because source URLs resolve relative to `index.json`, the directory is portable between static hosts.

## S3 setup

Use an S3 Standard bucket with versioning enabled. The repository defaults to a bucket named `dominaitrix-registry` in `us-east-1`; bucket names are globally unique, so suffix it with the AWS account ID and region if necessary, then update the extension default and publishing command together.

For a direct public S3 endpoint, allow public `s3:GetObject` only for objects in this bucket. Never grant public write access. A minimal CORS configuration is:

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["If-None-Match"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 86400
  }
]
```

Prefer CloudFront with Origin Access Control when moving beyond the proof of concept; it lets the bucket remain private and adds caching and traffic controls.

`pnpm registry:publish` builds the registry and runs an `aws s3 sync --dryrun`, including remote deletions in the preview. Add `-- --apply` only after reviewing that diff. AWS credentials come from the normal AWS CLI credential chain and must never be stored in this repository.

The generated index is uploaded with `Cache-Control: no-cache`. Clients retain its ETag and use `If-None-Match`, so an unchanged check normally returns a small `304 Not Modified` response. Adapter files are downloaded only on first installation or when their registry record changes.
